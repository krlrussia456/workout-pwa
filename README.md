# Workout PWA

Мобильный журнал тренировок, опубликованный через GitHub Pages.

## Функции
- В каждой карточке: раскрываемая техника, внешняя анимация или изображение и первоисточник (25 упражнений из справочника).
- Мягкие колокольные звуки таймеров, регулируемая громкость, тест сигнала.
- Внешние изображения требуют интернет-соединения.

- 16 упражнений и 36 подходов по плану на 15 ноября 2026.
- Изменение веса и повторений для каждого подхода.
- Таймер подхода, отдыха и общей продолжительности тренировки.
- Локальное сохранение в браузере; импорт и экспорт JSON.
- Офлайн-доступ после первой загрузки через service worker.

## Публикация
Workflow: `.github/workflows/deploy.yml`.
В GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Ожидаемый URL: https://krlrussia456.github.io/workout-pwa/

## Важно
Это MVP, а не автоматическая синхронизация с приватным `food-diary`.
Данные сохраняются только в localStorage на конкретном устройстве.
После тренировки экспортируй JSON для резервной копии. Удаление данных браузера удаляет локальную историю.
Токены GitHub не хранятся в исходном коде.
