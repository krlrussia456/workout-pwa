# Workout PWA

Мобильный журнал тренировок, опубликованный через GitHub Pages.

## Функции
- В каждой карточке: раскрываемая техника, внешняя анимация или изображение и первоисточник (25 упражнений из справочника).
- Мягкие колокольные звуки таймеров, регулируемая громкость, тест сигнала.
- Внешние изображения требуют интернет-соединения.

- 16 упражнений и 36 подходов по плану на 15 ноября 2026.
- Изменение веса и повторений для каждого подхода.
- Таймер подхода, отдыха и общей продолжительности тренировки.
- Локальное сохранение в браузере; импорт и экспорт JSON.
- Офлайн-доступ после первой загрузки через service worker.

## Публикация
Workflow: `.github/workflows/deploy.yml`.
В GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Ожидаемый URL: https://krlrussia456.github.io/workout-pwa/

## Важно
Это MVP, а не автоматическая синхронизация с приватным `food-diary`.
Данные сохраняются только в localStorage на конкретном устройстве.
После тренировки экспортируй JSON для резервной копии. Удаление данных браузера удаляет локальную историю.
Токены GitHub не хранятся в исходном коде.

## Версия 1.7
- Выбор даты тренировки, локальная история по датам, отдельные записи.
- План на 17 ноября с 36 подходами и усиленным прессом; для других дат используется шаблон этого плана.
- Опциональное сохранение завершённых тренировок в `workouts/YYYY-MM-DD-xxxxxxxx.json` **публичного** репозитория через GitHub API с fine-grained PAT (Contents: Read and write).
- Загрузка публичного архива в локальную историю. Токен сохраняется лишь в `sessionStorage`, но для приватности предпочтителен экспорт в `food-diary`.
- Автоматическая фоновая синхронизация без отдельного сервера и OAuth не реализована.


## Дашборд здоровья

- [Открыть дашборд](https://krlrussia456.github.io/workout-pwa/dashboard.html)
- Выбор одного дня или произвольного периода; средние значения за дни,
  для которых записаны соответствующие показатели; графики динамики.
- Данные читаются **только** из `stats/daily.json`. В приложении нет входа,
  токена GitHub, доступа к приватному дневнику или исходным названиям продуктов.
- JSON — публичный, содержит только числа с датами и сводки тренировок
  без деталей. Любой посетитель может просмотреть эти значения.
- Экспорт из приватного `food-diary` запускает GitHub Actions при обновлении
  `data/**`; для автоматической публикации нужен один раз настроенный
  `PUBLIC_STATS_TOKEN` **только в секретах приватного репозитория**.
  Пока секрет не настроен, публикация новых значений не автоматизирована.
